# Two apps for my grandmother

She lives in Mangalia and can't really operate a phone, so these are built to need
no learning at all. Both are installed on her home screen and both work with no
internet connection.

| Folder | App | Open it |
|---|---|---|
| [`quran/`](quran/) | **Coranul** — Quran audio player: two giant buttons (Surah Yaseen, the complete Quran), tap to play, tap again to pause, always resumes exactly where she stopped | https://enislucas.github.io/quran-player/quran/ |
| [`prayer/`](prayer/) | **Namaz Vakti** — prayer times for Mangalia: no buttons at all, the prayer window that is open right now glows, today's five windows are listed below | https://enislucas.github.io/quran-player/prayer/ |

Each folder has its own README with setup and day-to-day details.
[`CLAUDE.md`](CLAUDE.md) explains how the repository is put together, how to push
an update so it actually reaches her phone, and how the prayer times are produced.

## Putting them on her phone

Open the app's link in the phone's browser, then:

- **Android (Chrome):** ⋮ menu → *Add to Home screen* (may say *Install app*)
- **iPhone (Safari):** Share → *Add to Home Screen*

Do this once per app and two normal-looking icons appear on her home screen.
For the Quran player, leave it open on Wi-Fi the first time until it says
**✓ Disponibil offline** — that is a one-time ~770 MB download.
